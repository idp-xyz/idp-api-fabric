# Engineering Portal 契约评审

运行 `go run ./cmd/fabric-portal`。服务默认监听 `127.0.0.1:8081`，连接 `http://127.0.0.1:8080` 的 Fabric API。使用 `IDP_FABRIC_PORTAL_HTTP_ADDR` 和 `IDP_FABRIC_PORTAL_API_URL` 可以指定绑定地址和 API 源站。

将门户放到内部门户的 OIDC 登录代理之后。代理完成登录和会话验证，并为请求在服务器端附上面向 Fabric API 的短时 `Authorization: Bearer …`。登录代理应保留浏览器的请求来源和原始主机名，供门户校验跨站提交。Fabric API 验证令牌，并对每个操作重新检查产品与 Workspace 权限。

作者选择已留下检查证据的修订及审批范围，再提交评审。独立评审人打开队列和检查证据，批准或驳回。可豁免的规则需要逐条填写理由，本页面的豁免与批准同时到期。产品负责人可以浏览本产品队列。此入口仅转发流程使用的管理 API，门户及 API 响应禁止缓存。

接入企业登录代理后，在隔离环境使用两个具名测试账号验证提交、评审、跨产品拒绝与撤权，并将记录加入 WP-07。仓库的开发签发器可以用来验证真实 API 与 PostgreSQL 的联调。
