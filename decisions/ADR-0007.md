# ADR-0007 — 受限访问失败关闭与受控公开内容撤销

- **状态**：Proposed（未具名批准）
- **文档基线**：V1.0，不独立升级版本
- **关联**：F01 FR-025/034/036/049/063；F02 AI-03/04/07；F03 INV-08/09；F04 §10；F05 §5/8/9/16。

## 问题
跨产品共用开发者门户和契约 Registry 时，受限内容可能通过对象直链、搜索投影、私有缓存或 CDN 边缘残留继续被访问。把“主库已撤销”误当作“全球缓存已清除”会产生不可接受的安全假设。

## 候选决策
1. 受限内容每次服务端检查 Product、Audience、Environment、Grant、Release、PublicationSlot 和有效 AccessBlock；授权来源失败时拒绝（INDETERMINATE 不默许访问）。
2. PUBLIC 内容需显式发布批准并接受可能被第三方复制的现实；紧急 Block 必须先阻断受控源站，再通过缓存清理及边缘状态监控传播。仅在受控检测范围内将 Edge 标记已确认，不宣称已下载内容可召回。
3. 在初期采用服务端鉴权/BFF 受限分发或经安全评审的短时能力 URL，不对私有制品依赖长期公共 CDN 缓存；撤销不能只依赖 TTL。
4. 安全发布与撤销以 `Target × APIAsset` 的 Slot 为基本粒度，主库 CAS 和阻断代际分离；可以单独存在 Target-wide Block。

## 备选与权衡
- **只做 CDN purge**：实现简单，无法保证授权取消立即生效。
- **所有内容永久不缓存**：降低风险但影响公开文档成本和体验。
- **公开/受限差异化分发与拒绝优先**：具备可验证边界，需要额外工程联调和监控。

## 需验证及批准
F07 真实 IAM/Origin/CDN/对象存储断连和传播试验、下载直链、权限撤销、恢复演练；F08 按风险等级具名批准发布控制和残余风险。任何生产阈值均 TBD。

> 本 ADR 仅为设计提案，不能当作完成部署或通过安全测试的证明。
