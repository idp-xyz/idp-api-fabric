# ADR-0003 — 契约来源采用 Git-first 与单修订单权威

- **状态**：Proposed（设计候选，未具名签核）
- **日期**：2026-11-09
- **文档基线**：V1.0（不单独递增工程基线）
- **关联**：F02 §7–8；F01 FR-013–022、NFR-03/04。

## 背景
API 合同可能来源于产品 Git 仓库或受控人工导入。若允许 Git、平台编辑器和门户各自回写，无法确认哪份是可信原始定义。

## 推荐决策
默认通过 Git 提交形成导入 Revision；授权人工上传可作为另一来源类型，存原始文件、摘要与操作者。每个 Revision 的来源类型唯一、内容不可原地覆盖；修订必须另建 Revision。

## 备选方案与权衡

- **强制 Git Only**：利于持续集成，但不利于外部合作方的受控导入。
- **平台编辑器与 Git 双主写入**：便利但易产生冲突与来源不明。
- **Git-first + 受控上传**：在可追溯的前提下兼容各类来源。

## 后果与约束
来源证明不是放宽授权；网络引用闭包固定；入库文件不可成为任意远程获取/执行入口。

## 关闭条件与证据
模拟 Git Commit 与文件摘要不匹配、重复提交、上传/转换失败；NOT_RUN。
