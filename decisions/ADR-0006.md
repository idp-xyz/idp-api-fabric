# ADR-0006 — 仅集成 IAM、Gateway、Git 与 CI，不替代运行时数据平面

- **状态**：Proposed（设计候选，未具名签核）
- **日期**：2026-11-09
- **文档基线**：V1.0（不单独递增工程基线）
- **关联**：F02 §3/§12/§15；F01 非目标 2–4、FR-056–061。

## 背景
Fabric 的核心职责是契约治理、发布与开发者体验。若自己实现 OAuth Provider、通用 Gateway 或 CI Runner，将发生能力膨胀和安全责任重叠。

## 推荐决策
使用 Port/Adapter + ACL 集成可信 IAM / API Gateway / Git / CI；Fabric 管理元数据与接入流程，不签发生产令牌、不运行货运业务 API。每个适配器定义不可用、重试、过期及审计语义。

## 备选方案与权衡

- **内建所有外部平台功能**：功能独立但成本、安全与运维复杂度高。
- **完全依赖特定供应商 SDK**：建设较快，产生耦合和供应商锁定。
- **受限 Ports/Adapters**：替换成本与权限边界更清晰。

## 后果与约束
某些实现能力可能不可兼容，必须使用适配器契约验证和退出策略；适配成功不代表业务 API 授权成功。

## 关闭条件与证据
断连、凭证到期、重复事件、Gateway Drift 不可达等场景；NOT_RUN。

> 本 ADR 是架构决策提案。若 PoC、F03–F08 设计或安全审查发现不可满足的约束，必须重新评审；不得将“Proposed”描述为“Approved”。
